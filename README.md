# Adored Us

Freelance services site for websites, logos, and business setup (Google Workspace + Google Business Profile), with clear rate cards.

**Live site:** [pauravi14.github.io/adored](https://pauravi14.github.io/adored/)

## Open locally

Open `index.html` in your browser, or:

```bash
python -m http.server 8765
```

## Deploy

GitHub Pages workflow in `.github/workflows/pages.yml` (push to `main`).
